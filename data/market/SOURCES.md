# Market data sources

`returns.json` and the shrinkage `estimates.json` are generated by `uv run python scripts/build_market_data.py` and are not fetched at runtime. `backtest.json` is generated by `uv run python scripts/backtest_market.py`.

- **Equity and cash:** [Kenneth R. French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html), Fama/French 3 Factors monthly file. Equity is `Mkt-RF + RF`; cash is `RF`. The library identifies the data as copyrighted by Kenneth R. French; retain the source attribution and use it for research/educational purposes.
- **REITs:** the same library's value-weighted 49 Industry Portfolios file, `RlEst` column. It is a US-market proxy and is subject to the library's stated terms.
- **Bonds:** [FRED GS10](https://fred.stlouisfed.org/series/GS10), Board of Governors 10-year Treasury constant-maturity yield. The builder converts yield changes to an approximate monthly total return using duration 6; it is not a bond index.
- **Gold:** [World Bank Commodity Price Data (Pink Sheet)](https://thedocs.worldbank.org/en/doc/5d903e848db1d1b83e0ec8f744e55570-0350012021/), distributed in the public datasets mirror as [`datasets/gold-prices`](https://github.com/datasets/gold-prices). Gold is the monthly price return; no storage or carrying cost is modeled.

The result is historical research data, not an investable index or a promise of future returns. Check each provider's current terms before redistribution or commercial use.
